# 一、	背景與動機

　　本專題主題為「使用DBMS與RAG建置無人機法規與知識問答系統」。會選擇這個題目，主要與組員們的修課經驗有關。上學期我們三位組員曾修習同一語言模型（LLM），由模型在選擇題的 A、B、C、D選項中作答，並以最後的答題正確率觀察其在無人機法規問題上的表現。由於我們當時已對這類應用有初步接觸，因此在本學期資料庫系統課程需要選擇專題題目時，看到老師提供的題目中包含LLM相關方向，便優先考慮這個主題。
　　我們組對資料庫系統的實作經驗較少，過去也沒有接觸過 DBMS 的設計與建置，我們希望藉由這次專題實作，實際了解如何將資料庫技術應用到一個系統上。相較於完全陌生的題目，無人機法規與知識問答系統至少在主題內容上與我們先前接觸過的 LLM 應用有一定連結，因此比較適合作為我們的發展方向。
　　此外，組內有兩位成員本身有接觸無人機相關領域，對於無人機法規之外的知識內容，例如操作知識、應用情境與相關資料來源，也較清楚應該從哪些網站、文件或公開資源進行蒐集。這使得我們在規劃系統內容時，更能夠建立一個能提供較完整資訊的問答系統。
　　基於以上原因，我們決定以無人機法規與知識問答作為專題方向，並嘗試結合DBMS與RAG的方法進行系統建置。一方面藉此熟悉資料庫的設計、儲存與查詢方式，另一方面也延伸先前對LLM應用的基礎經驗，讓系統可以透過檢索與生成的方式，回應使用者對無人機法規及相關知識的提問。

# 二、	專案目標

　　本專題旨在設計並實作一套以資料庫管理系統（DBMS）為核心之檢索增強生成（Retrieval-Augmented Generation, RAG）問答系統，應用領域聚焦於無人機操作知識與相關法規。透過DBMS的資料管理與向量檢索能力，建立一個可供大型語言模型查詢與引用的領域知識庫，使其在回答無人機操作、飛行安全、法規限制與證照學科題目時，能夠提供較具依據性、正確性與可解釋性的答案。
　　本研究選擇以「無人機操作證學科筆試」作為主要應用情境。無人機學科筆試通常涵蓋飛行基本知識、飛行安全規範、空域觀念、操作責任、緊急應變與相關法規條文等內容，這些知識多半散見於法規文本、手冊說明、題庫資料與教學整理之中。若能將這些資料轉換為可檢索之知識庫，並透過大型語言模型進行語意整合與答案生成，將有助於提升考生準備效率。

---

### 　為了達成上述整體成果，本專題進一步設定以下幾項具體目標：
-	建構無人機操作與法規之領域知識庫
-	設計適合文字知識管理的 DBMS 儲存架構
-	建立以 DBMS 為基礎的向量檢索機制
-	整合大型語言模型與檢索結果生成答案
-	驗證系統對學科筆試題目的應用可行性
